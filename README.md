# 新進國小立體校園地圖

115 學年度立體互動校園地圖：各棟建築樓層配置、逃生路線（紅色箭頭）與大操場班級集合位置。

- 線上版：https://diberchi.github.io/xinjin-3d-campus-map/
- 資料來源：`115上-01逃生路線和集合位置(導師版)-逃生地圖-無引導-以升旗位置為主.docx`
- 參考：雙溪高中立體互動校園導覽地圖（Three.js 低多邊形風格）

## 功能

- 滑鼠拖曳旋轉、右鍵平移、滾輪縮放；手機可用手指操作
- 點建築 → 右側顯示概要、樓層與避難方向；點樓層會切開大樓看該層教室
- 搜尋教室（例：`234`、`校長室`）或班級（例：`四3`）直接定位
- 「班級集合點」分頁：點班級會在大操場上標出位置
- 逃生路線、集合位置、標籤可個別開關；夜間模式、自動導覽
- 深連結：網址加 `#四3` 或 `#b1` 可直接打開該班集合點或建築

## 修改資料

所有教室、樓層、集合位置與逃生路線都在 `data.js`，座標是原平面圖上的像素位置（北方朝上）。

- 換教室名稱：改 `buildings[].floors` 裡的名稱
- 換班級順序：改 `assembly.row.classes`
- 改逃生路線：改 `routes[].pts`
